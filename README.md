# Tepu Solutions Limited

Source for the Tepu Solutions Limited website, built with React, TypeScript, and TanStack Start.

## Development

Install dependencies with Bun (`bun install`), then run `bun run dev`.

The inquiry form uses the project's Supabase backend. Configure the required Supabase environment variables locally before running server-side inquiry submission. Do not commit `.env` files or secret keys.

The `src/assets/*.asset.json` manifests reference media managed by the original Lovable deployment.
